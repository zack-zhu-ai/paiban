# 护理排班系统

纯前端网页，数据存在 GitHub 私有仓库里（通过访问令牌读写），平板、电脑打开同一个网址就能用。

- 网址：https://zack-zhu-ai.github.io/paiban/
- 数据：私有仓库 `paiban-data` 里的 `data.json`（本仓库不含任何人员或排班数据）

## 第一次使用
1. 打开网址，点「设置」
2. 粘贴访问令牌（设置页里有生成步骤），点「保存并连接」
3. 平板上用浏览器的「添加到主屏幕」，之后像 App 一样打开，断网也能用

## 文件
- `index.html`：整个系统（界面、计算、Excel 导出、GitHub 同步都在这一个文件里）
- `sw.js`、`manifest.webmanifest`、图标：离线使用和「添加到主屏幕」
